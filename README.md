Here you will find the code needed for generating polar plots (in MLT and L-shells) that show the distribution of plasma density in Earth's outer radiation belt. 
- This code implemnts data from RBSP-A specifically, but can be used for RBSP-B.
- Loads in MagEphem data for magnetic field data, EMFISIS L4 data for plasma density, and Kyoto World Data Center for Auroral Electrojet (AE) Index.
- Calculates ratio of plasma density over magnetic field strength (wpe/wce), plots the normalized occurence of these points in MLT.
- Data distributed by AE Index range, and data normalized per index range.
